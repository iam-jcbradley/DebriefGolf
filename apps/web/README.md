# apps/web

Debrief Golf frontend — Next.js 15 (App Router, TypeScript), Tailwind CSS, shadcn/ui.

```bash
pnpm install
pnpm dev      # http://localhost:3000
pnpm test     # vitest
pnpm lint
pnpm build
```

See the root [`README.md`](../../README.md) and [`docs/`](../../docs/) for the full project overview, PRD, and development plan.
